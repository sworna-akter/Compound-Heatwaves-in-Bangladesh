
# Data Documentation

This directory documents the datasets used in the compound heatwaves in Bangladesh research.

## Data Sources

| Dataset | Variables | Period | Source |
| ERA5 Reanalysis | 2 m temperature, dewpoint, surface pressure | 1991–2025 | ECMWF/Copernicus |
| ERA5 Reanalysis | Precipitation and cloud cover | 1991–2025 | ECMWF/Copernicus |
| ERA5 Reanalysis | Wind components | 1991–2025 | ECMWF/Copernicus |
| ERA5 Reanalysis | Soil moisture | 1991–2025 | ECMWF/Copernicus |
| ERA5 Reanalysis | Surface solar radiation | 1991–2025 | ECMWF/Copernicus |

## Data Access

ERA5 datasets are available through the Copernicus Climate Data Store:

https://cds.climate.copernicus.eu/

## Data Processing

The original datasets were processed using Python-based scientific and geospatial libraries.

## Important Note

Raw meteorological and satellite datasets are not redistributed in this repository. Users should obtain the original data from the respective providers and follow their data access and usage conditions.
