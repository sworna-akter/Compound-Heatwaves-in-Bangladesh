
# Research Methodology

This directory documents the methodological framework, analytical procedures, and statistical techniques used in the study of daytime, nighttime, and compound heatwaves across Bangladesh during the pre-monsoon season (1991–2025).

## Methodological Components

1. Data acquisition and preprocessing
2. Heatwave identification and classification
3. Heatwave characteristics and metrics
4. Temporal trend analysis
5. Spatial analysis
6. Climatic driver assessment

Detailed methodological documentation and supporting materials will be added to this directory.
